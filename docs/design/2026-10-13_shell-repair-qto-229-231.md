# Honest `mesh_qto` on surface models — design for GH #229 + #231

Status: adopted 2026-10-13 (coordinator decision after a code-architect
pass). Implementation lands in the sequence under "Build sequence".

## Problem (from the v0.6.4 discovery sweep)

1. For a mesh whose net face-area vector S = Σ aᵢ nᵢ ≠ 0 the signed-tetra
   volume depends on the reference point: V(o) = V(0) − o·S/3. `qto.rs::compute`
   integrates about the world AABB-min, so six identical translated joists
   report 0.0046 → 0.0216 m³. ≈ 1 400 rows corpus-wide, ≈ 1 150 of them
   `volume_reliable=True` (Clinic Structural joists, Clinic Architectural
   coverings, HI90_BIMK windows — class sum 178.6 vs 46.7 m³ coherent —,
   KNM_LARK one-sided sheets declared Closed=.T., Plumbing faucets/WCs).
   The physical truth is the per-connected-set coherently re-oriented
   volume; it matches Revit's authored `Volume` pset to 1e-9 on 151
   coverings. (GH #229)
2. Revit MEP "Generic" fittings author 2–6 coincident body items (same #id
   twice in Items, identical extrusions, near-identical brep pairs). Both
   kernels sum the copies; the winding-number union ≈ ifcopenshell/2; our
   rule-2 catch routes to a prism +24 % over the union. 661/1 647 Plumbing
   fittings → 17.8 % of a model on the fallback. (GH #231)
3. ifcopenshell is not a usable oracle on these rows (GH #230): its number
   is also frame-dependent.
4. Corpus-wide `volume_reliable=False` is almost never wrong (≤ 71/2 448);
   the false-negative side is the problem.

## Decision

Fix the volume in QTO by repairing the shell — not by moving the origin,
not in the mesher, not by trusting a different oracle. Rows that need no
repair keep today's output bit for bit.

A new `crates/core/src/mesh/shell.rs` analyses a mesh in two cases: rows
not `closed`, and `closed` rows with ≥ 2 raw components. It (1) drops
near-duplicate solid copies (#231), (2) cancels coincident opposite face
pairs (never changes the volume), (3) collapses faces present more than
once with the same winding, (4) re-orients each connected face set and
judges the whole repaired surface. A repaired surface with no remaining
boundary becomes `closed` / `volume_method="mesh_repaired"` with an exact,
origin-independent volume. Anything else gets a typed reason and is routed
out. `mesh_open` narrows: an open shell is trusted only when its residual
holes are crack-sized (bounded), no longer merely because it sits inside
the prism band. Two new nullable columns: `shell_defect`, `shell_repair`.
`brep.rs` does not change (winding stays as authored; mesh bytes for glTF /
clash / substrate / hotswap are untouched).

## Patterns the design rests on

- `qto.rs::compute` (≈ 205–665): bbox first, signed-tetra sum about the
  box-min in f64 (266–343), `classify_mesh_quality` (457), routing
  (507–645). The comment at 224–234 ("translation-invariant") is only true
  when S = 0.
- `classify_mesh_quality` rules: no box volume → degenerate; |V| > box →
  open_shell; edge balance raw then after 0.1 mm weld; same-winding
  duplicate face → open_shell; all faces cancelled → degenerate.
  `stats.rs:227` calls the same function (drift table = QTO).
- A boundary-free chain always has S = 0, so `closed` rows are already
  origin-independent; the #229 problem lives in the `mesh_open` band
  (626–638). Two premises of that band are refuted: #131's "the oracle
  cancels identically" (only held because both sides shared a frame on
  G55) and #121's "these rows match ifcopenshell".
- Three unit tests encode the behaviour #229 calls wrong and are rewritten
  as part of the contract change: `open_shell_within_prism_bound_keeps_mesh_value`
  (cube without a top trusted at 5/6), `open_shell_low_fill_keeps_mesh_not_inflated_prism`,
  `prism_fallback_replaces_garbage_volume_on_open_shell` (doubled cube →
  repairs to exactly 1).
- `brep.rs::closed_shell` caches vertices per shell by STEP id, so raw
  components approximate authored items/shells; FBSM/SBSM concatenate;
  authored `Orientation` is honoured per bound (same as ifcopenshell).
- wasm `qtoJson` sums the raw origin-dependent `volume.abs()` and splits
  reliable/unreliable only on `clip_unapplied` (+ `profile_invalid` from
  #220) — prism-fallback and every #229 row are "reliable" in the browser.
- #220 (`wt/gh220`, merged as cache v42) adds `profile_invalid`,
  `mark_profile_invalid`, `apply_product_flags` as the single post-compute
  hook, and method `mesh_profile_invalid` over `mesh | mesh_open`. Use its
  diff as the plumbing checklist.

## Algorithm — `shell::analyze(vertices, indices, unit_scale) -> ShellOutcome`

All f64; every table sorted, never HashMap-iterated (GH #152 determinism).

Gate (inside `compute`, after `classify_mesh_quality`, before the prism
raster): rows labelled `closed` with exactly one raw component take today's
path bit-identically (union-find folded into the existing `EdgeChain::of`
loop). Everything else enters `analyze`: `open_shell` from any rule;
`degenerate` rows with non-zero box volume (keep label unless repair finds
a closed set); `closed` rows with ≥ 2 raw components (#231 "closed
fittings", inside-out components, nested voids).

- S1 Raw components: union-find over raw indices; per component bbox,
  `vol6` about its own box-min, area, area vector s, `closed_welded`,
  sorted triangle list.
- S2 Drop near-duplicate components (#231): bucket by bbox quantised at
  δ_c = max(weld_eps, 1e-4·diag_c). Both closed: bbox corners within δ_c,
  |V| within 1e-3 rel, area within 1e-2 rel, ≥ 90 % vertex coverage
  (quantised, 27-neighbour lookup; guards against mirror images). One
  closed one open: every vertex of the open one in the closed set, every
  triangle sharing ≥ 2 vertices with a coplanar triangle (dot ≥ 1−1e-6),
  A_open ≤ 1.01·A_closed. Keep the lowest index; set `duplicate_items`.
- S3 Weld (existing `welded_indices`), drop degenerate triangles, then
  `collapse_coincident_faces`: group by sorted triple, net parity n; n = 0
  → drop group (cancels opposite pairs, volume unchanged for every origin);
  |n| ≥ 1 → one copy with sign(n), |n| ≥ 2 sets `duplicate_faces`.
- S4 Orientation sets: sorted edge table; BFS in triangle order across
  edges with exactly 2 incidences; contradiction = conflict for that set.
  1-incidence edges are boundary; ≥ 3 (multiplicity-4 coincident
  opposites, self-touching lobes, fins) are cut, not traversed — the
  "split at multiplicity-4" that stops naive BFS reporting false conflicts.
- S5 Set sign: closed-within-itself sets → sign making V_set ≥ 0 (void
  rule aside); open sets → authored-majority sense. `reoriented` if any
  face flipped relative to authored.
- S6 Voids: for closed pairs with box containment, winding number at the
  centroid of the inner set's first triangle (van Oosterom–Strackee);
  |w| ≥ 0.5 and opposite authored sense → void (subtract); same sense →
  `overlapping_solids`.
- S7 Judge: rebuild balance over the repaired chain; `volume_raw` about the
  product box-min (S is now 0 so it is only conditioning); `closed` =
  balanced ∧ no conflicts ∧ Σ|V_closed sets| ≤ box·1.001 (else
  `overlapping_solids`).
- S8 Crack bound: walk unbalanced directed edges into loops; B = Σ|vector
  area of each loop| (origin-independent); crack_ratio = B·diag/(3|V|).
  Filling the holes moves the volume by at most about that fraction, and
  |S| ≤ B bounds the origin sensitivity.
- S9 Residual open sets: `one_sided_surface` if |S_set| ≥ 0.5·A_set (flat
  sheet scores 1.0, cube missing one face 0.17), else `open_boundary`;
  `non_orientable` if conflicts.

Outcome table (decided in `compute`):

| Outcome | `mesh_quality` | `volume_method` | reliable | `volume_best_m3` | `shell_defect` |
|---|---|---|---|---|---|
| did not enter analyze | unchanged | unchanged | unchanged | bit-identical | null |
| analysed, no repair, crack ≤ 1e-3, passes existing band + collapse checks | unchanged | mesh / mesh_open | true | bit-identical | null |
| repaired chain closed (or crack ≤ 1e-3) | closed (open_shell if crack) | mesh_repaired | true | \|volume_raw\|·unit³ | null |
| residual sets all one-sided, ≥ 1 closed set | open_shell | mesh_closed_sets | false | Σ closed sets (lower bound) | one_sided_surface |
| all sets one-sided, no closed set | degenerate | prism_fallback | false | 0 | one_sided_surface |
| anything else | open_shell | prism_fallback | false | prism raster | non_orientable > overlapping_solids > open_boundary > one_sided_surface |

`shell_repair` = tokens joined by `+` in fixed order (`reoriented`,
`duplicate_items`, `duplicate_faces`), a u8 bitmask into a static table.
`volume_m3` / `volume_mesh_m3` keep the raw authored sum for audit. Rows
repaired to `closed` get `volume_prism_bound_m3 = NaN` and skip the raster.
Reference point stays the box-min (centroid rejected: a fourth arbitrary
origin while S ≠ 0, tessellation-dependent, changes every closed row's bits).

Thresholds: CRACK_RATIO_MAX 1e-3; ONE_SIDED_S_OVER_A 0.5; DUP_VOL_REL 1e-3;
DUP_AREA_REL 1e-2; DUP_VERTEX_COVERAGE 0.9; DUP_DELTA_REL 1e-4·diag floored
at weld_eps; OVERLAP_AABB_MARGIN 1.001; NEST_WINDING 0.5; coplanar dot ≥ 1−1e-6.

## Cost

Single-component closed rows: ~10 ns/triangle union-find in an existing
loop, bits unchanged. Multi-component closed rows: one O(T) summary pass +
duplicate checks only among colliding boxes. Non-closed rows: sorted edge
table O(T log T) + BFS + boundary loops + winding on nested candidates —
smaller than the three 256×256 rasters those rows already pay; rows that
repair to closed skip the raster. QTO runs serially in the sink thread, so
cost shows in wall-clock: budget ≤ 3 % end-to-end on G55_RIV, measured in
commit 1 (`#[ignore]` timing test, ns/triangle per path).

## Rejected

Switch the reference point to the centroid (fourth arbitrary origin while
S ≠ 0; hides the defect; changes every closed row's bits; tessellation-
dependent). Dedupe by name or #id (655/662 Plumbing rows are distinct
entities). Repair winding in `brep.rs` (changes mesh bytes for glTF / clash /
substrate / hotswap; sees one shell, not product-level duplicates). Cap
holes to close open shells (tray vs solid-missing-a-face are
indistinguishable; invents volume). Monte-Carlo union in the core (random,
no stable bits, slow — harness only). Keep the prism band as the trust rule
(trusts a cube missing a face at 5/6 and ≈ 1 150 origin artefacts). Revive
#131's coherence gate (distrusts without repairing). General CSG union for
partial overlaps (no evidence yet; robust boolean on the hot path against
the manifold-retirement direction — ship the Σ > box tripwire, file a
follow-on with an MC measurement plan).

## Risks

Contract change (`mesh_open` narrower, more rows routed out; the "~0.3 %"
claim is already false — Plumbing 17.8 %). The 0.1 mm weld can bridge
sub-0.1 mm features into false conflicts (fails safe: flagged). Void rule
rests on a one-point winding test. Duplicate predicate false positives
(vertex coverage guards mirrors). Serial sink makes cost visible.
