this if it can be avoided." Delivered:

- **Toolchain**: system Rust (Arch) has no wasm target; rustup installed
  user-locally (`~/.cargo/bin`, `--no-modify-path`) with
  `wasm32-unknown-unknown` + `wasm-bindgen-cli`. Native builds keep using
  `/usr/bin/cargo`.

  intended space-free set (216 nodes / 415 GUID materials vs 227 / 426).
  Duplex in Node: 221 ms parse+extract+mesh, 6 ms glb; `.wasm` 1.07 MB.
