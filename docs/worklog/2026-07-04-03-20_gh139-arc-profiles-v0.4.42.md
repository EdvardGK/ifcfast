  #123 circular/degree case:
  - **IfcEllipse basis** (SemiAxis1/SemiAxis2) and **IfcLine basis**

    to `a`/`b`; new `conic_arc`, `trimmed_line_2d`, `vector_2d`,
    `trim_line_param` helpers.

    model's declared plane-angle unit from `IfcUnitAssignment.Units`
    (RADIAN→1.0, DEGREE conversion-unit→its π/180 factor) and scales
    PARAMETER trims by it. **Default stays degrees** (Revit/ArchiCAD omit the
    declaration) so the circle+degree hot path is arithmetically identical.
    CARTESIAN trims now divide out the ellipse semi-axes before `atan2`
    (identity for a circle).

    on `EntityTable` via `OnceLock` (`unit_assignment_id()`) — one scan per
    model, not per arc. On G55_ARK the assignment is the **penultimate**
    entity of ~2.8M, so the initial per-arc `table.iter().find()` was
    O(arcs × entities) — a real meshing-time regression on the exact file we
    gate on. Fixed before commit.
  - Cache schema **27 → 28**.
